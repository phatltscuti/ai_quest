Source note: Karpathy — LLM Wiki (gist)

Source: https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

Main ideas excerpt — not a full copy of the original.

  • RAG vs. wiki: classic RAG re-fetches chunks and re-derives answers on each question; an LLM Wiki is a compounding artifact — structured Markdown that keeps getting compiled and maintained.
  • Where it sits: the wiki layers between immutable raw sources and you; the agent updates wiki/ under rules in a schema like CLAUDE.md or AGENTS.md.
  • Workflow: Ingest (read a source, touch many wiki pages) → Query (use index.md then drill in; persist strong answers back into the wiki) → periodic Lint (contradictions, stale claims, orphans).
  • Navigation files: index.md orients by topic; log.md orients by time (append-only).
  • Tooling: Obsidian for live reading & Graph view; optional local search (qmd, etc.) or MCP-backed retrieval when the vault grows.
