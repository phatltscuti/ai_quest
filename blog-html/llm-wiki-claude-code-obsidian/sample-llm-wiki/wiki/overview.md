# LLM Wiki — sample vault overview

This vault illustrates the **LLM Wiki** pattern: knowledge is **compiled** into linked Markdown instead of being re-retrieved chunk-by-chunk on every question.

## What this sample is for

- **`raw/`** holds **one** short immutable source note.
- **`wiki/`** holds the **compiled layer** maintained by the agent; you read it in Obsidian.
- **`CLAUDE.md`** is the **schema** so Claude Code (or an equivalent agent) stays consistent.
