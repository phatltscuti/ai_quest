Preparation checklist for legacy projects at an outsourcing company

Applying the six steps to legacy modernization projects (PHP / Java / VB) for Japanese clients. Tick every box before letting agents run at scale.

Uplift (same stack, newer version)

The stack still works; only the runtime / libraries are out of support.

e.g. PHP 5.x → PHP 8.x, Java 8 → 17/21, Spring Boot 2 → 3

Transform (new stack, same behavior)

Behavior is trusted; the language / framework is the problem.

e.g. VB6 / VB.NET WinForms → C# .NET, Struts → Spring

Reimagine (rebuild, new behavior)

Code and business logic both change; needs a new written spec.

e.g. on-premise internal system → web/SaaS with new workflows

1. Target & Spec

Uplift / Transform / Reimagine chosen together with the client
Dependency map built from build logs / imports / runtime traces
Business rules extracted from code, with file citations, reviewed by the client
Project rationale written down (EOL, vulnerabilities, no maintainers)

2. Certificate & Policy

List of automatically checkable conditions (tests, coverage, benchmarks, scans)
Old/new output comparison or data replay (PII masked)
Review tiered by impact; critical paths still get full review
Review report format agreed with reviewers / client

3. Environment & CI/CD

Dedicated remote host; Claude Code can access code and docs
Environment that runs the legacy system (Docker) for comparison
Code freeze policy + plan to notify active developers
CI blocks commits that break modernized parts

4. Security & Contract

Client approves sending source code to the model (per NDA / contract)
Least privilege: write only to the modernization branch, no production credentials
Secrets and personal data masked
Each PR links the agent transcript + certificate evidence; new dependencies checked for license/CVE
GATE
Scale to the whole codebase only when: a pilot on one small partition has completed the full loop (agent change → certificate passes → policy-based review → merge) and token usage has been measured to estimate cost.
