Six-step roadmap to prepare for AI-driven code modernization

When agents write code faster, the bottleneck shifts to the organization: the target, the definition of "correct", the review process and the infrastructure must be ready first.
PREPARE: align people and the organization (start step 4 in parallel with steps 1 to 3)
EXECUTE: agents do the work, humans review
1
Define the Target
Where are we going?
  • Pick a type: Uplift / Transform / Reimagine
  • Map the codebase, extract a behavioral spec
  • Project rationale: reducing risk often matters more than cutting cost
Output: target definition + spec
▶
2
Define the Certificate
What counts as "correct"?
  • Machine-checkable conditions
  • Legacy tests, new tests, coverage, benchmarks, scans, adversarial review, old/new output diffs
  • Would a reviewer merge on this evidence alone?
Output: written certificate
▶
3
Promotion Policy
Who reviews, and how deeply?
  • Tier by blast radius and agent confidence
  • Fix recurring errors at the source (workflow / certificate)
  • Save SME time for high-risk tiers
Output: tiered review policy
▶
4
Prerequisites
Is the infrastructure ready?
  • Environment: remote hosts, test capacity, telemetry / replay
  • Codebase + CI/CD: dependency map, code freeze
  • Team and reviewers
  • Security: least privilege, masked secrets/PII, audit trail
Output: environment + access + schedule
▶
5
Build & Refine Workflow
Do agents work reliably?
  • Start from the code modernization plugin
  • Put target, certificate, policy on the file system / MCP
  • Trial on a small slice, SME review
  • Fix the workflow, not individual changes
Output: reusable workflow
▶
6
Run the Modernization
Scale safely
  • End-to-end pilot on one small partition
  • Separate build (Transform/Reimagine) or In-place (Uplift)
  • In-place: work from leaves inward, freeze each part, gate CI/CD
Output: new code + evidence trail
Token cost: measure on the pilot, then extrapolate; run expensive checks after cheap ones; use a cheaper model (Sonnet) for mechanical work the certificate verifies and a stronger model for hard parts and adversarial review; track retry rates.
Assets that outlive the project: the modernized codebase, a reusable workflow, a written certificate, an approved promotion policy, an evidence trail for every change, and a playbook for next time.
