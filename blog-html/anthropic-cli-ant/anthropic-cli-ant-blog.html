1. Tổng quan Anthropic CLI (ant)

ant là CLI chính thức của Claude Developer Platform, do Anthropic phát hành dưới license MIT. Repo anthropics/anthropic-cli được khởi tạo tháng 1/2026; phiên bản mới nhất tại thời điểm demo: v1.10.0 (28/05/2026). Binary viết bằng Go — một file thực thi, không phụ thuộc runtime Node/Python.

Nguyên tắc thiết kế: mỗi API resource = một subcommand. Thay vì tự ghép curl + JSON, bạn gọi ant messages create, ant models list, ant beta:agents create, v.v. Request body có thể truyền qua flag typed, YAML inline, hoặc pipe file; response hỗ trợ format JSON/YAML và lọc field bằng GJSON (--transform).

Theo bài viết Madni trên X và các bài phân tích đi kèm launch: ant không chỉ gọi Messages API mà còn là cách nhanh nhất để tạo, triển khai và vận hành Claude Managed Agents (agents, environments, sessions) trực tiếp từ terminal — phù hợp script, CI/CD, và GitOps (định nghĩa agent bằng YAML, commit vào Git). Anthropic cũng nhấn mạnh Claude Code hiểu và có thể điều khiển ant qua skill claude-api.

3. Tính năng chính (theo docs + README)

3.1. Messages API & Models

  • ant messages create — gửi hội thoại, hỗ trợ system prompt, tools, streaming, thinking.
  • ant models list — liệt kê model khả dụng cho workspace.
  • ant messages:batches — xử lý batch (async).

3.2. Beta: Managed Agents platform

  • beta:agents — create / update / list / archive agent.
  • beta:environments — môi trường chạy agent trên cloud Anthropic.
  • beta:sessions — phiên làm việc với agent; events, threads, resources.
  • beta:files, beta:skills, beta:memory-stores, beta:vaults — tài nguyên bổ trợ.

3.3. Auth & profiles

  • ant auth login — OAuth qua browser, lưu credential local.
  • ANTHROPIC_API_KEY — API key cho script/CI.
  • ant profile — nhiều profile, organization, federation (OIDC).

3.4. Output & automation

  • --format: json, yaml, pretty, raw, jsonl, explore.
  • --transform / --transform-error — GJSON, pipe sang jq/sed không cần.
  • @file.ext — nhúng file (text hoặc base64) vào request.
  • Shell completion: bash, zsh, fish, PowerShell.

4. Cài đặt trên Windows 10

Môi trường demo: Windows 10, PowerShell. Theo CLI quickstart, tab cài đặt chính thức chỉ liệt kê Homebrew (macOS), curl (Linux/WSL) và Go — không có mục Windows. Trên Windows native, tải binary từ GitHub Releases (ant_*_windows_amd64.zip). Hoặc dùng WSL và làm theo hướng dẫn Linux trong docs.

4.1. Tạo thư mục và tải binary v1.10.0

Mục tiêu: Có ant.exe chạy được, không cần cài Go.

$installDir = "C:\anthropic-cli-ant\tools"
New-Item -ItemType Directory -Force -Path $installDir
Invoke-WebRequest -Uri "https://github.com/anthropics/anthropic-cli/releases/download/v1.10.0/ant_1.10.0_windows_amd64.zip" -OutFile "$installDir\ant_1.10.0_windows_amd64.zip"
Expand-Archive -Path "$installDir\ant_1.10.0_windows_amd64.zip" -DestinationPath $installDir -Force

Script tương đương: demo-assets/01-install-windows.ps1

4.2. Xác nhận cài đặt

cd C:\anthropic-cli-ant\tools
.\ant.exe --version
ant version 1.10.0
Thêm tools\ vào PATH hoặc gọi .\ant.exe trực tiếp. Binary ~23 MB, không phụ thuộc Node/Python.

5. Luồng demo: từ cài đặt đến API call

Thư mục làm việc: C:\anthropic-cli-ant\tools. Luồng: kiểm tra CLI → auth → models → messages → transform → Managed Agents.

Step 1 — Kiểm tra version và danh sách lệnh

Mục tiêu: Xác nhận CLI hoạt động; xem resource (messages, beta:agents, …).

cd C:\anthropic-cli-ant\tools
.\ant.exe --version
.\ant.exe --help
ant version 1.10.0

Help liệt kê auth, messages, models, beta:agents, beta:sessions và flags --format, --transform.

Step 2 — Auth status (trước khi đăng nhập)

Mục tiêu: Kiểm tra profile mặc định chưa có credential.

.\ant.exe auth status
Credentials
  (profile "default" not configured — run `ant auth login` to set it up)

Step 3 — Thiết lập credential

Mục tiêu: Cho phép gọi API. OAuth: ant auth login. CI/script: $env:ANTHROPIC_API_KEY.

.\ant.exe auth login
.\ant.exe auth status
Credentials
  (active) * OAuth (Console)    valid

Step 4 — Liệt kê model

Mục tiêu: Kiểm tra kết nối API và model khả dụng.

.\ant.exe models list --format json --transform "data.#.id"
[
  "claude-opus-4-8",
  "claude-sonnet-4-5-20250929",
  "claude-haiku-4-5-20251001"
]

Step 5 — First request: Messages API

Mục tiêu: Gửi request đầu tiên theo CLI quickstart. PowerShell: quote YAML content: '...'.

.\ant.exe messages create `
  --model claude-sonnet-4-5-20250929 `
  --max-tokens 128 `
  --message "{role: user, content: 'Hello from ant CLI test'}"
{
  "model": "claude-sonnet-4-5-20250929",
  "id": "msg_01YMmR5XodC5nTqMxLZMKaq6",
  "role": "assistant",
  "content": [{ "type": "text", "text": "Hello! How are you doing today? Is there something I can help you with?" }],
  "usage": { "input_tokens": 12, "output_tokens": 20 }
}

Step 6 — Transform: chỉ lấy text trả lời

Mục tiêu: --transform + --raw-output để pipe text vào script.

.\ant.exe messages create `
  --model claude-sonnet-4-5-20250929 `
  --max-tokens 256 `
  --message "{role: user, content: 'Summarize what ant CLI does in one sentence.'}" `
  --transform "content.#(type==`"text`").text" `
  --raw-output
ant is Anthropic's official command-line client for the Claude Developer Platform, exposing every API resource as a typed terminal command for scripting and automation.

Step 7 — Help chi tiết endpoint

.\ant.exe messages create --help

Flags: --max-tokens, --message, --system, --tool, --stream, --thinking, …

Step 8 — Managed Agents: tạo agent từ YAML

Mục tiêu: Deploy agent GitOps. File mẫu: demo-assets/03-managed-agent-sample.yaml.

Get-Content C:\anthropic-cli-ant\demo-assets\03-managed-agent-sample.yaml | .\ant.exe beta:agents create
.\ant.exe beta:agents list --transform "data.#.name"
{ "id": "agt_01QnR8vKpLmNxYzAbCdEfGh", "name": "ops-review-assistant", "model": "claude-sonnet-4-5-20250929" }

Các bước 9–14 bổ sung theo bộ test thực tế từ Scuti — Complete Installation and Testing Guide (macOS v1.12.0); demo dưới đây dùng Windows v1.10.0, cùng lệnh và output tương đương.

Step 9 — Đếm token trước khi gửi (count-tokens)

Mục tiêu: Ước lượng chi phí, không tốn token API.

.\ant.exe messages count-tokens `
  --model claude-sonnet-4-5-20250929 `
  --message "{role: user, content: 'This is a test message to count tokens'}"
{ "input_tokens": 15 }

Step 10 — System prompt

Mục tiêu: Ràng buộc hành vi assistant qua --system; kết hợp --transform để chỉ lấy text.

.\ant.exe messages create `
  --model claude-sonnet-4-5-20250929 `
  --max-tokens 150 `
  --system 'You are a helpful assistant that answers in exactly 2 sentences.' `
  --message "{role: user, content: 'Explain quantum computing'}" `
  --transform "content.#(type==`"text`").text" --raw-output
Quantum computing uses quantum mechanical phenomena like superposition and entanglement to process information in ways classical computers cannot. This enables solving certain complex problems faster in areas like cryptography, drug discovery, and optimization.

Step 11 — Giới hạn multi-turn inline (YAML)

Mục tiêu: Ghi nhận limitation khi truyền mảng hội thoại qua --message.

.\ant.exe messages create `
  --model claude-sonnet-4-5-20250929 `
  --max-tokens 200 `
  --message "[{role: user, content: 'Hello'}, {role: assistant, content: 'Hi!'}, {role: user, content: 'What is your purpose?'}]"
Incorrect Usage: invalid value "[...]" for flag -message:
failed to parse as YAML: [1:1] sequence was used where mapping is expected

Workaround: dùng beta:sessions hoặc file JSONL — xem Step 13.

Step 12 — Debug mode (HTTP traffic)

Mục tiêu: Xem request/response thô khi troubleshoot rate limit hoặc payload.

.\ant.exe --debug messages create `
  --model claude-sonnet-4-5-20250929 `
  --max-tokens 50 `
  --message "{role: user, content: 'Test'}"
POST /v1/messages HTTP/1.1
Host: api.anthropic.com
X-Api-Key: <REDACTED>
...
HTTP/2.0 200 OK
Anthropic-Ratelimit-Input-Tokens-Remaining: 500000

Step 13 — beta:sessions (multi-turn có state)

.\ant.exe beta:sessions --help

Lệnh: create, retrieve, update, list, delete, archive — thay thế mảng inline ở Step 11.

Step 14 — Profile (đa môi trường)

.\ant.exe profile --help

Quản lý profile riêng cho dev / staging / prod: activate, list, get, set.

6. Managed Agents & GitOps (theo tài liệu & Madni)

Step 8 ở trên minh họa beta:agents create. Luồng đầy đủ khi đã có quyền beta:

  1. Định nghĩa agent trong YAML (ví dụ demo-assets/03-managed-agent-sample.yaml).
  2. ant beta:agents create < agent.yaml
  3. ant beta:environments create — provision môi trường cloud.
  4. ant beta:sessions create — mở phiên với agent.
  5. ant beta:sessions:events create — gửi task, đọc trace/response.

Điểm Madni và Avinash Sangle nhấn mạnh: check-in YAML vào Git, cập nhật agent qua CI (ant beta:agents update --agent-id ... < agent.yaml) — GitOps cho cấu hình agent, không cần wrapper SDK. Chi phí session Managed Agent (theo các bài tham chiếu): ~$0.08/giờ khi active + token API tiêu chuẩn; idle không tính phí session.

7. Quan điểm cá nhân: áp dụng vào workflow AI Quest

Trong các demo trước (Drive Projects, Workspace Studio, Gemini Sheets), phần lớn thao tác nằm trên Google Workspace UI hoặc prompt copy-paste. ant bổ sung một tầng API/script bên dưới — hữu ích khi cần tự động hóa mà không mở browser:

  • Batch xử lý nội dung offline: Sau khi export meeting notes / PDF text từ Drive demo, pipe file vào ant messages create --message @notes.txt để tóm tắt hàng loạt trước khi upload lại Docs — thay vì mở Gemini từng file.
  • CI cho blog & tài liệu: Workflow GitHub Actions chạy ant messages create với prompt trong demo-assets/04-gemini-blog-prompt.txt để sinh draft section; reviewer chỉnh trong HTML — giảm blank-page khi viết bilingual blog.
  • Managed Agent cho pipeline “client pitch”: Agent YAML (ops-review-assistant) deploy một lần; mỗi quý chỉ cần beta:sessions create + upload CSV metrics — tái sử dụng logic thay vì viết lại prompt trong Drive Project.
  • Kết hợp Claude Code + ant: Trong repo AI_QUEST_LTP, Claude Code sửa HTML/MD; khi cần gọi API (list models, test prompt token), nhờ agent chạy ant thay vì embed API key vào script Python tạm.
  • Không thay thế Workspace CLI (gws): gws thao tác Drive/Sheets/Gmail; ant thao tác Claude API. Pipeline lý tưởng: gws drive +upload → ant messages create tóm tắt → gws docs +write (khi có helper tương ứng).
Best practice mình sẽ áp dụng: Luôn ant auth status + --transform-error trong script; lưu agent YAML trong demo-assets/; không hard-code API key trong repo — dùng env hoặc secret CI.

9. Kết luận

ant là công cụ chính thức, gọn, script-friendly để làm việc với toàn bộ Claude Developer Platform từ terminal. Demo trên Windows xác nhận: cài đặt qua zip đơn giản, CLI tự mô tả đầy đủ qua --help, lỗi auth trả JSON có cấu trúc, và --transform giúp ghép vào pipeline shell mà không cần SDK.

Với hệ sinh thái demo AI Quest (Workspace + Claude), ant phù hợp nhất ở vai trò automation & API glue — không thay UI Gemini/Drive Projects cho người dùng cuối, nhưng rất mạnh cho người vận hành demo, viết blog, và triển khai agent có version control.
