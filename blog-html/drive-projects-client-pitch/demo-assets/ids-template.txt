HƯỚNG DẪN LẤY ID / LINK (điền vào các dòng bên dưới sau khi tạo xong trên Drive)

────────────────────────────────────────
1) ID thư mục (Folder)
────────────────────────────────────────
- Mở folder trên Drive (double-click vào folder).
- Nhìn thanh địa chỉ trình duyệt, URL dạng:
  https://drive.google.com/drive/folders/XXXXXXXXXXXXXXXX
- Phần XXXX sau chữ "folders/" chính là Folder ID → dán vào đây.

────────────────────────────────────────
2) ID Google Doc
────────────────────────────────────────
- Mở Doc (double-click file).
- URL dạng:
  https://docs.google.com/document/d/XXXXXXXXXXXXXXXX/edit
- Phần XXXX sau "/d/" và trước "/edit" là Doc ID.

Hoặc trên Drive (chưa mở Doc): bấm chuột phải file → Share → Copy link
  https://drive.google.com/file/d/XXXXXXXX/view
  → ID nằm giữa "/d/" và "/view" (cùng một chuỗi với Docs URL).

────────────────────────────────────────
3) Link Drive Project
────────────────────────────────────────
- Sau khi tạo Project, URL trên trình duyệt thường chứa project (copy nguyên URL).
- Nếu không có ID riêng: chỉ cần ghi full URL vào "Project URL" là đủ cho demo nội bộ.
